# Module 1: Database & Flyway Migration

## Database Strategy
- **Database Engine:** PostgreSQL
- **Migration Tool:** Flyway (`org.flywaydb:flyway-database-postgresql`)
- **Hibernate Mode:** `spring.jpa.hibernate.ddl-auto=validate`
  - Hibernate does **not** alter or auto-create tables. It strictly validates that the JPA `User` entity matches the Flyway-managed schema at startup.

## Migration File
Location: `src/main/resources/db/migration/V1__create_users_table.sql`

```sql
CREATE TABLE users (
    user_id    BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name       VARCHAR(100) NOT NULL,
    email      VARCHAR(255) NOT NULL,
    password   VARCHAR(255) NOT NULL,
    role       VARCHAR(30)  NOT NULL,
    active     BOOLEAN      NOT NULL DEFAULT TRUE,
    created_at TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT uk_users_email UNIQUE (email),
    CONSTRAINT chk_users_role CHECK (role IN ('STUDENT', 'TPO', 'RECRUITER'))
);

CREATE INDEX idx_users_email ON users (email);
```

## Schema Columns
| Column | SQL Type | Constraints | Notes |
| :--- | :--- | :--- | :--- |
| `user_id` | `BIGINT` | `PRIMARY KEY`, `GENERATED BY DEFAULT AS IDENTITY` | Maps to `Long userId` (`GenerationType.IDENTITY`) |
| `name` | `VARCHAR(100)` | `NOT NULL` | Display name (2–100 chars) |
| `email` | `VARCHAR(255)` | `NOT NULL`, `UNIQUE (uk_users_email)` | Stored in lowercase; indexed via `idx_users_email` |
| `password` | `VARCHAR(255)` | `NOT NULL` | BCrypt hash only (never plain text) |
| `role` | `VARCHAR(30)` | `NOT NULL`, `CHECK` (`STUDENT`, `TPO`, `RECRUITER`) | Stored as string via `@Enumerated(EnumType.STRING)` |
| `active` | `BOOLEAN` | `NOT NULL DEFAULT TRUE` | Controls whether user can log in / authenticate |
| `created_at` | `TIMESTAMP` | `NOT NULL DEFAULT CURRENT_TIMESTAMP` | Maintained by `@CreatedDate` |
| `updated_at` | `TIMESTAMP` | `NOT NULL DEFAULT CURRENT_TIMESTAMP` | Maintained by `@LastModifiedDate` |
